# Vocabee

Бесплатное расширение Chrome для перевода отдельных слов и выделенных фраз в субтитрах YouTube. Перевод вызывается только для текста субтитров и выделенного фрагмента субтитров, не для комментариев.

## Возможности

- Перевод слов и выделенного текста на русский, английский, украинский или немецкий.
- Пауза видео при наведении на субтитр или карточку перевода.
- Озвучивание оригинала и перевода, копирование результата.
- Popup, плавающая панель YouTube и карточка перевода построены на React; интеграция с YouTube и Chrome API остаётся в отдельных модулях.
- Плавающая панель на YouTube открывается на словаре; словарь и настройки доступны по отдельным кнопкам. В настройках можно регулировать общий размер текста интерфейса и размер слов и переводов в словаре.
- Панель можно перемещать, изменять её размер, сворачивать и скрывать; положение, размер, состояние и выбранный раздел сохраняются после перезагрузки.

## Сборка

Требуется Node.js 20 или новее.

```sh
npm ci
npm run build
```

Готовое расширение появится в `dist/`.

## Локальная разработка

Запустите локальный сайт словаря:

```sh
npm run dev
```

Команда запускает полноэкранный сайт словаря и автоматически открывает его в браузере. Если расширение загружено в Chrome и обновлено после сборки, сайт на `localhost` получает записи из его локальной IndexedDB через content-script-мост; настройки страницы также сохраняются в настройках расширения. Если соединение с расширением недоступно, сайт явно сообщает об этом и показывает отдельное локальное хранилище сайта. Браузер изолирует IndexedDB веб-сайта от базы расширения, поэтому без расширения localhost не может читать базу напрямую. Страница словаря включена в сборку расширения как `dist/dictionary.html` и читает ту же базу, что пополняется на YouTube. Vite пересобирает popup и YouTube-интерфейс после изменения исходников.

Чтобы проверить расширение на YouTube и открыть его общую базу слов, откройте `chrome://extensions`, включите **Режим разработчика**, выберите **Загрузить распакованное расширение** и укажите папку `dist/`. На YouTube значок расширения по-прежнему показывает плавающую панель; на других страницах он открывает полноэкранный словарь расширения. После первой загрузки или изменений манифеста (в том числе content-script-моста для localhost) нажмите кнопку перезагрузки расширения в `chrome://extensions`, затем обновите страницу словаря. HMR в расширениях Chrome не используется.

Для обычной одноразовой сборки запустите `npm run build`.

## Структура проекта

```text
manifest.json    Манифест Chrome Manifest V3 (для загрузки корня проекта)
src/
  background.js  Обработчик нажатия на значок расширения
  content/       Логика YouTube и React-интерфейс
    content-app.jsx  Точки входа React-панели и карточки перевода
    panel/        Компоненты и хуки панели; у JSX-компонентов свои CSS Modules
    tooltip/      Компоненты и хук карточки; у JSX-компонентов свои CSS Modules
  icons/         Иконки расширения
  popup/         React-компоненты и хуки; у JSX-компонентов свои CSS Modules
  dictionary/    Полноэкранная страница словаря и доступ к IndexedDB
vite.config.js   Сборка и упаковка файлов расширения
vite.content.config.js  Сборка React content script
```

Сборка собирает popup и отдельный классический React-бандл для content scripts, затем адаптирует пути манифеста для `dist/`. Это генерируемая папка; её содержимое не нужно редактировать вручную.

Нажатие на значок Vocabee на странице YouTube открывает или скрывает плавающую панель со словарём. Нажатие на название Vocabee в шапке панели открывает словарь; кнопки словаря и настроек переключают разделы. Панель восстанавливает положение, состояние и открытый раздел после перезагрузки страницы.

## Данные и ограничения

Для перевода выделенный текст отправляется в Google Translate через используемый проектом endpoint. Это неофициальный endpoint без гарантии доступности или лимитов; сервис может ограничить запросы. Не используйте расширение для текста, который не следует передавать сторонним сервисам.

Кнопка «Добавить в словарь» сохраняет исходный текст и перевод в IndexedDB расширения. Нажми «Мой словарь» в плавающей панели YouTube, чтобы увидеть сохранённые слова. Одинаковые слова для одной и той же пары языков не дублируются. Данные локальные для этого браузерного профиля и пока не синхронизируются с телефоном.

Расширение рассчитано на Chrome и английские/немецкие субтитры. Сборка для Safari пока не настроена.
