# Vocabee

Бесплатное расширение Chrome для перевода отдельных слов и выделенных фраз в субтитрах YouTube. Расширение также может обрабатывать текст комментариев.

## Возможности

- Перевод слов и выделенного текста на русский, английский, украинский или немецкий.
- Пауза видео при наведении на субтитр или карточку перевода.
- Озвучивание оригинала и перевода, копирование результата.
- Переключатель расширения и выбор языка в popup.

## Сборка

Требуется Node.js 20 или новее.

```sh
npm ci
npm run build
```

Готовое расширение появится в `dist/`. Можно загрузить в Chrome папку проекта `Vocabee/` напрямую: корневой `manifest.json` ссылается на исходники в `src/`. Также можно загрузить собранную папку `dist/`.

Для локальной установки откройте `chrome://extensions`, включите **Режим разработчика**, выберите **Загрузить распакованное расширение** и укажите `Vocabee/` или `Vocabee/dist/`.

## Структура проекта

```text
manifest.json    Манифест Chrome Manifest V3 (для загрузки корня проекта)
src/
  content/       Скрипты и стили, работающие на YouTube
  popup/         Интерфейс и настройки расширения
vite.config.js   Сборка popup и упаковка файлов расширения
```

Сборка адаптирует пути манифеста для `dist/`. Это генерируемая папка; её содержимое не нужно редактировать вручную.

## Данные и ограничения

Для перевода выделенный текст отправляется в Google Translate через используемый проектом endpoint. Это неофициальный endpoint без гарантии доступности или лимитов; сервис может ограничить запросы. Не используйте расширение для текста, который не следует передавать сторонним сервисам.

Словарь пока не реализован: кнопки «Мой словарь» и «Добавить в словарь» показывают интерфейс будущей функции, но слова ещё не сохраняются.

Расширение рассчитано на Chrome и английские/немецкие субтитры. Сборка для Safari пока не настроена.
