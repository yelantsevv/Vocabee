# Vocabee

Vocabee — приложение для изучения английского и немецкого языков. Веб-словарь помогает повторять слова и выражения, а расширение для Google Chrome переводит субтитры YouTube и сохраняет полезные карточки в «Мой словарь».

## Возможности приложения

### Словари и обучение

- Встроенные словари **EN → RU** и **DE → RU**, загружаемые отдельно в настройках.
- «Мой словарь» с карточками, добавленными через расширение Vocabee.
- Просмотр слов и фраз с фильтрами по уровню, категории, типу глагола и прогрессу изучения.
- Карточки с переводом, примерами употребления, формами глаголов, синонимами и антонимами.
- Озвучивание слов, фраз и примеров с выбором доступного голоса для английского или немецкого.
- Режим обучения и отметки прогресса: «Не знаю», «Учу», «Знаю».
- Настройка количества примеров, видимости перевода и связанных слов, темы и размеров текста.
- Сохранение выбранного словаря, фильтров, настроек и учебного прогресса между посещениями.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

### Расширение Vocabee для Chrome

- Перевод выбранных слов и фраз в английских или немецких субтитрах YouTube на русский язык.
- Настройка языка субтитров EN/DE и озвучивание карточек на соответствующем языке.
- Добавление переведённых выражений из субтитров в «Мой словарь».
- Плавающая панель со словарём, прогрессом карточек и настройками отображения.
- Пауза видео при наведении на распознанный субтитр или окно перевода, а также на время озвучивания карточки.
- Обмен карточками и прогрессом с веб-словарём, когда расширение установлено и связь доступна.

Расширение предназначено для **настольного Google Chrome** на Windows, macOS и Linux. Оно работает на YouTube и не устанавливается в мобильные браузеры.

## Начало работы со словарём

1. Откройте приложение Vocabee.
2. В настройках загрузите **EN → RU** или **DE → RU**. Словарь можно выбрать и изменить в любое время.
3. Используйте фильтры каталога, чтобы подобрать слова или фразы для просмотра.
4. Откройте обучение, чтобы повторять карточки и отмечать прогресс.

Чтобы использовать «Мой словарь», установите расширение Vocabee для Chrome на компьютере и добавляйте слова из субтитров YouTube.

## Установка расширения Chrome

1. [Скачайте архив расширения Vocabee](https://github.com/yelantsevv/Vocabee/blob/dev/vocabee.zip?raw=1).
2. Распакуйте ZIP-файл в постоянную папку на компьютере.
3. Откройте в Google Chrome страницу `chrome://extensions/`.
4. Включите переключатель **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку с файлом `manifest.json`.
6. Откройте или обновите YouTube. Нажмите значок Vocabee на панели Chrome, чтобы включить перевод.

Не перемещайте и не удаляйте папку расширения после установки. После установки новой версии обновите Vocabee на странице `chrome://extensions/`.

## Разработка

Нужны Node.js и npm. Команды запускаются из корня репозитория.

```sh
npm install
npm run dev
```

`npm run dev` запускает локальный словарь и пересобирает интерфейсы popup и расширения при изменениях. Для проверки расширения соберите его и загрузите папку `dist/vocabee` через `chrome://extensions/` с включённым режимом разработчика. Локальный мост словаря работает на `localhost:5173` и `127.0.0.1`; после изменений манифеста перезагрузите расширение в Chrome.

## Команды сборки

```sh
npm run build:app              # popup и интерфейс расширения → dist/vocabee
npm run build:dictionary       # веб-словарь → dist/dictionary
npm run build                  # обе сборки
npm run build:dictionary:pages # версия веб-словаря для GitHub Pages
```

## Структура проекта

```text
src/
├── dictionary/                 # React-приложение веб-словаря
│   ├── components/             # Каталог, карточки, обучение и настройки
│   ├── config/                 # Конфигурация приложения
│   ├── data/                   # IndexedDB и браузерное хранилище
│   ├── hooks/                  # Состояние каталога и настроек
│   ├── styles/                 # Общие стили и темы
│   └── utils/                  # Фильтры, прогресс и вспомогательная логика
└── vocabee/                    # Расширение Chrome Manifest V3
    ├── background/             # Service worker и личный словарь
    ├── components/settings/    # Общие элементы настроек
    ├── content/                # YouTube, плавающая панель и окно перевода
    ├── popup/                  # Popup расширения
    ├── shared/                 # Общие настройки и тема
    └── manifest.json           # Разрешения и точки подключения
```

Основные технологии: React, Vite, JavaScript modules, IndexedDB, Web Storage API и Chrome Extensions Manifest V3.

Интерфейс веб-словаря находится в `src/dictionary`, код расширения — в `src/vocabee`.
