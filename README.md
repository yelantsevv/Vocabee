# Vocabee

Vocabee помогает пополнять словарный запас во время просмотра видео и повторять слова в отдельном словаре. Проект состоит из веб-приложения для изучения слов и расширения Chrome для перевода субтитров YouTube.

## Возможности

### Словарь и обучение

- Каталоги EN → RU и DE → RU, а также «Мой словарь» с выражениями, сохранёнными через расширение.
- Фильтрация слов и фраз по языку, уровню, категории и статусу изучения.
- Карточки с переводом, примерами, формами глаголов и озвучиванием.
- Режим обучения с отметками «Не знаю», «Учу» и «Знаю».
- Прогресс и настройки сохраняются между посещениями; приложение использует браузерное хранилище и IndexedDB.
- Настройки отображения, озвучивания, примеров и связанной лексики.

### Расширение Chrome

- Переводит выбранные английские слова и фразы в субтитрах YouTube.
- Озвучивает перевод и позволяет сохранить английское слово или фразу из субтитров в «Мой словарь».
- Показывает плавающую панель со словарём и настройками темы, размера текста и перевода субтитров.
- Приостанавливает видео, пока указатель находится над субтитром или переводом.

Перевод субтитров и добавление слов из подсказок поддерживают только английский язык. Расширение предназначено только для браузера Google Chrome на компьютере (Windows, macOS или Linux). Оно не устанавливается в мобильные браузеры и работает на сайте YouTube.

## Установка расширения из архива

1. [Скачайте архив Vocabee](https://github.com/yelantsevv/Vocabee/blob/dev/vocabee.zip?raw=1).
2. Распакуйте ZIP-файл в удобную папку. Не удаляйте и не перемещайте файлы из этой папки после установки.
3. Откройте в Chrome страницу `chrome://extensions/`.
4. Включите переключатель **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку, в которой находится `manifest.json`.
6. Откройте или обновите YouTube. Значок Vocabee появится на панели Chrome; через него можно включать и выключать перевод.

После обновления архива распакуйте его в папку и нажмите кнопку обновления карточки расширения на странице `chrome://extensions/` либо загрузите новую папку.

## Запуск проекта локально

Нужны Node.js и npm.

```sh
npm install
npm run dev
```

Команда `npm run dev` запускает локальный словарь и следит за изменениями интерфейса расширения. Для разработки расширения загрузите его собранную папку через `chrome://extensions/` с включённым режимом разработчика. Локальный мост расширения рассчитан на `localhost:5173` и `127.0.0.1:5173`; после изменения манифеста перезагрузите расширение в Chrome.

## Сборка

```sh
npm run build:app
npm run build:dictionary
```

- `npm run build:app` собирает popup и интерфейс расширения.
- `npm run build:dictionary` собирает веб-приложение словаря.
- `npm run build` запускает обе сборки.
- `npm run build:dictionary:pages` собирает сайт словаря для GitHub Pages.

## Структура проекта

```text
src/
├── dictionary/                 # React-приложение словаря
│   ├── components/             # Каталог, карточки, обучение и настройки
│   ├── config/                 # Конфигурация и быстрые действия
│   ├── data/                   # Работа с базой словаря и хранилищами
│   ├── hooks/                  # Состояние каталога и настроек
│   ├── styles/                 # Общие стили и темы
│   └── utils/                  # Фильтрация, прогресс и вспомогательная логика
├── vocabee/                    # Расширение Chrome Manifest V3
│   ├── background/             # Service worker и хранилище слов расширения
│   ├── content/                # Перевод субтитров и плавающая панель YouTube
│   ├── popup/                  # Popup расширения
│   ├── shared/                 # Общие настройки и тема
│   └── manifest.json           # Разрешения и точки подключения расширения
└── ...                         # Точки входа и конфигурация сборки находятся в корне
```

## Вклад в проект

Перед изменениями проверьте соответствующие инструкции и область ответственности модулей. Изменения интерфейса словаря размещайте в `src/dictionary`, а код браузерного расширения — в `src/vocabee`.
