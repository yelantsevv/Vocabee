# Vocabee для Google Chrome

Расширение помогает переводить слова и короткие фразы в субтитрах YouTube, озвучивать их и сохранять в личный словарь. Здесь описаны установка, использование и разработка расширения.

> Расширение предназначено для настольного Google Chrome на Windows, macOS и Linux. Оно работает на YouTube. В мобильных браузерах расширение не поддерживается.

## Возможности

- Включение и выключение перевода субтитров через значок Vocabee на панели Chrome.
- Перевод выбранного слова или фразы в субтитрах YouTube на русский язык.
- Выбор языка исходных субтитров: английский (EN) или немецкий (DE). Выбор применяется к распознаванию текста субтитров, переводу и списку личного словаря.
- Озвучивание карточек на выбранном языке с помощью доступного в Chrome системного голоса.
- Автоматическая пауза видео при наведении на распознанный субтитр или окно перевода. Если видео воспроизводилось перед озвучиванием карточки, после озвучивания оно продолжит воспроизведение.
- Добавление переведённых слов и фраз из окна перевода в личный словарь.
- Просмотр личного словаря в плавающей панели, изменение уровня изучения, удаление карточек и обновление списка без перезагрузки страницы.
- Синхронизация карточек личного словаря с веб-приложением Vocabee при установленном расширении и доступном мосте связи.
- Настройки темы, языка субтитров и размера текста плавающей панели.

В списке личного словаря отображаются карточки выбранного языка: одновременно английские и немецкие карточки не смешиваются. Перевод субтитров и добавление слов из окна перевода доступны для английского и немецкого исходного текста.

## Установка из архива

1. Скачайте [архив расширения Vocabee](https://github.com/yelantsevv/Vocabee/blob/dev/vocabee.zip?raw=1).
2. Распакуйте архив в постоянную папку на компьютере.
3. Откройте в Google Chrome страницу `chrome://extensions/`.
4. Включите переключатель **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и выберите папку расширения с файлом `manifest.json`.
6. Откройте YouTube или обновите уже открытую вкладку. Нажмите значок Vocabee на панели Chrome, чтобы включить или выключить перевод.

Не удаляйте и не перемещайте выбранную папку после установки: Chrome загружает расширение из неё. После установки новой версии откройте `chrome://extensions/` и нажмите кнопку обновления на карточке Vocabee.

## Использование

1. На YouTube нажмите значок Vocabee, чтобы включить обработку субтитров.
2. В плавающей панели откройте настройки и выберите **Английский (EN)** или **Немецкий (DE)** согласно языку субтитров.
3. Наведите указатель на распознанное слово или выделите фразу в субтитрах. Vocabee покажет перевод.
4. Нажмите кнопку добавления в окне перевода, чтобы сохранить карточку в личный словарь.
5. Откройте раздел личного словаря в плавающей панели. В карточке можно включить озвучивание, отметить уровень изучения или удалить запись.

Если перевод не появляется, проверьте, что на видео включены субтитры, выбран правильный язык и расширение включено для этой вкладки. Для перевода требуется подключение к интернету.

## Разработка

Нужны Node.js и npm. Команды выполняются из корня репозитория:

```sh
npm install
npm run build:app
```

Сборка расширения создаётся в `dist/vocabee`. Чтобы проверить её в Chrome, откройте `chrome://extensions/`, включите режим разработчика и загрузите эту папку как распакованное расширение.

Для локальной разработки веб-приложения и интеграции расширения со словарём:

```sh
npm run dev
```

Команда запускает локальный сайт словаря и следит за изменениями popup и интерфейса расширения. Локальная связь расширения со словарём настроена на `http://localhost:5173/dictionary` и `http://127.0.0.1:5173/dictionary`. После изменения `manifest.json` перезагрузите расширение на странице `chrome://extensions/`.

## Структура исходников

```text
src/vocabee/
├── background/                 # Service worker, обработка сообщений и личный словарь
├── components/settings/        # Общие элементы настроек
├── content/
│   ├── panel/                  # Плавающая панель, личный словарь и настройки
│   ├── runtime/                # Перевод, язык субтитров, пауза и мост разработки
│   └── tooltip/                # Окно перевода и добавление карточек
├── icons/                      # Иконки расширения
├── popup/                      # Popup при нажатии на значок расширения
├── shared/                     # Общие хуки и настройки отображения
└── manifest.json               # Manifest V3, разрешения и точки подключения
```

Content runtime — классические скрипты, которые добавляют API в `globalThis.Vocabee`. Их порядок подключения задан в `manifest.json` и `background/action-controller.js`; при изменении списка сохраняйте согласованность обоих мест. React-точки входа интерфейсов — `popup/popup.jsx` и `content/content-app.jsx`.

## Технологии

- React и Vite
- JavaScript modules
- Chrome Extensions Manifest V3
- Chrome Storage API и IndexedDB для хранения данных личного словаря
- Web Speech API для озвучивания
