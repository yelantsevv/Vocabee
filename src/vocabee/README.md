# Браузерное расширение Vocabee

## Структура исходников

- `background/` — фоновый service worker, действия для вкладок, обработка сообщений и хранилище словаря.
- `components/settings/` — общие компоненты настроек для popup и панели YouTube.
- `content/` — интерфейс и стили content script.
  - `panel/` — плавающая панель, разделы словаря и настроек, хуки состояния панели.
  - `tooltip/` — подсказка с переводом субтитров и хук её состояния.
  - `runtime/` — интеграция со страницей браузера; файлы загружаются в порядке из `manifest.json`.
- `popup/` — popup расширения, его компоненты и хуки.
- `shared/` — хуки и функции настройки отображения, используемые в разных частях расширения.
- `icons/` — иконки расширения, на которые ссылается `manifest.json` или фоновый код.

Файлы content runtime — классические скрипты, которые добавляют API в `globalThis.Vocabee`. Сохраняйте их порядок в `manifest.json`. Точки входа React-интерфейса: `popup/popup.jsx` и `content/content-app.jsx`.
